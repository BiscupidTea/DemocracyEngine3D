# DemocracyEngine3D

**DemocracyEngine3D** is a custom **C++ game engine** developed as part of **three subjects** in a Video Game Development degree at **Image Campus**.

---

## Project Goals

- Learn and apply **game engine architecture** concepts
- Design reusable and modular **engine systems**
- Transition from a **2D pipeline to a 3D pipeline**
- Work close to the metal using **pure C++**
- Avoid engine-specific dependencies as much as possible

---

## Key Features

- Written **entirely in C++**
- Custom engine architecture
- Started as a 2D engine and evolved into 3D
- Focus on clean code and separation of responsibilities
- Educational but production-oriented mindset
